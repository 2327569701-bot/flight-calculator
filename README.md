## V3.1 做了什么？

- **新增在线航图入口** - 桌面版在飞行计算器的独立窗口中打开 ChartFox 官网；网页版在新标签页打开。

ChartFox 是第三方服务，与本项目没有隶属关系。航图仅供模拟飞行；请遵守 [ChartFox 使用条款](https://chartfox.org/legal/terms)。

## V3 做了什么？

### 工程地基清理
- **删除 V1 遗留的死代码** - `app.js`（2000+ 行）、`unitSystem.js`、`utils.js`、`profileManager.js`、`calculators/`、`styles.css` 等从未被加载的文件全部移除
- **彻底移除 Electron** - 删除 `main.js` / `preload.js`，移除 electron 依赖与打包脚本，只保留 Tauri
- **构建前自动清空 `dist`** - 重命名或删除的文件不会再残留在打包目录里
- **数据文件重排为可读形式** - 修正了垂直速度、三角计算在公制单位下未正确换算的问题

### 新增计算器：大气 · 空速
- **压力高度** - QNH（支持 hPa / inHg）+ 机场标高 → 压力高度
- **密度高度** - 压力高度 + 外界温度 → 密度高度，并给出 ISA 温度偏差；高温结果以警示色标出
- **真实空速** - 指示空速 + 压力高度，按每千英尺约 +2% 的经验修正估算 TAS

### 新增：历史记录与导出
- **自动记录** - 每次成功的计算自动存入历史（连续重复计算自动合并），本地持久化
- **一键复制** - 单条或全部记录复制为文本
- **导出 JSON / CSV** - 生成带时间戳的文件（CSV 含 BOM，Excel 打开中文不乱码）
- **打印** - 把整份计算记录排版后打印或另存为 PDF

- **更小更快** - 安装包更小，启动更快

## 关于技术栈

Tauri 基于 Rust + WebView2，轻量且可靠。

- **Tauri 2.0** - 轻量级跨平台桌面框架
- **原生 Web** - 纯 HTML/CSS/JavaScript，零运行时依赖
- **本地存储** - 单位、历史等所有数据存储于本地，保护隐私

> 说明：Rust 后端还内置了一套机型 / 单位预设的存取命令，当前界面尚未使用，预留给后续「多机型档案」迭代。

## 功能一览

| 计算器 | 说明 |
|--------|------|
| 下滑角 | 高度差+水平距离 → 下滑角（双向计算） |
| 垂直速度 | 地速+下滑角 → 垂直下降率 |
| TOD | 高度差 → 最佳下降点距离/时机 |
| 三角计算 | 速度/距离/时间，任意两值求第三值 |
| 大气·空速 | 压力高度、密度高度、真实空速 |
| VAPP | VREF+风修正+阵风 → 进近速度；风分量；VREF 查询 |
| 历史记录 | 自动保存计算，复制 / 导出 JSON·CSV / 打印 |
| 手册 | 导入本地 PDF，查看已有 FCOM 参考摘录 |
| 在线航图 | 在应用独立窗口中打开 ChartFox 官网，可切换到系统浏览器 |

## 单位系统

支持公制 / 英制 / 混合三种预设，以及完全自定义。

| 模式 | 距离 | 速度 | 高度 | 垂直速度 | 重量 |
|------|------|------|------|----------|------|
| 公制 | km | km/h | m | m/s | kg |
| 英制 | NM | kt | ft | ft/min | lb |
| 混合 | NM | kt | ft | ft/min | kg |

> 混合模式：航空专业单位(NM/kt/ft)搭配公制重量(kg)。
> 气压 QNH 可在每个计算器内单独切换 hPa / inHg；温度统一使用 °C。

## 待核对的进近速度规则

VAPP 沿用了旧版未经适用 B737-800 手册核实的风修正规则。当前代码对顶风和顺风都减小计算速度，而顺风说明写成了加速；内置摘录也不能当作已核实的 FCOM。此项需取得对应机型和操作方式的正式资料后修正，当前结果仅供模拟飞行，不可用于实际飞行。

## 运行方式

### 预览当前 UI

直接用浏览器打开 `index.html`，即可预览当前界面。支持浅色 / 深色主题、响应式导航、本地 PDF 手册导入与历史记录。

修改前端后执行 `npm run build:web`，将入口、样式和脚本同步至 Tauri 使用的 `dist` 目录（会先清空再拷贝）。`npm run tauri:build -- --no-bundle` 会先自动执行这一步，再生成独立 EXE；已有 EXE 不会随源码修改而自动更新。

### Windows 直接运行

从 [GitHub Releases](https://github.com/2327569701-bot/flight-calculator/releases/latest) 下载 `Flight-Calculator-V3.1.exe`，双击即可运行，无需启动网页服务器或安装 Node.js。

本地项目目录中的程序名为 `Flight Calculator V3.1.exe`；`启动飞行计算器.bat` 和 `npm start` 也会启动它（找不到 V3.1 时回退到旧版）。程序使用 Windows WebView2 Runtime。

### 从源码构建 Windows 版本

安装 Node.js、Rust 和 Visual Studio C++ 构建工具后执行：

```sh
npm install
npm run test:diagrams
npm run tauri:build -- --no-bundle
```

独立程序位于 `src-tauri/target/release/flight-calculator.exe`。构建时会自动将最新前端同步到 `dist`。

请保留仓库中的 `src-tauri/Cargo.lock`：它固定了已验证的依赖版本。

图形动画回归检查：先运行 `npx playwright install chromium`，再执行 `npm run test:animation`。也可以设置 `PLAYWRIGHT_CHANNEL=msedge` 使用已安装的 Edge。
