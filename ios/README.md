# iOS Edition

这个目录用于存放 `Flight Calculator` 的 iOS 版本工程。

当前已包含：

- `FlightCalculator Xcode/`：Xcode 工程目录

建议从下面这个工程文件打开：

- `FlightCalculator Xcode/FlightTest.xcodeproj`

说明：

- iOS 版本当前采用 `SwiftUI + WKWebView` 容器方案
- 网页资源位于 `FlightCalculator Xcode/FlightTest/WebApp/`
- 这一版已经接入 V2 的网页资源，适合继续做 iOS 适配和打磨
